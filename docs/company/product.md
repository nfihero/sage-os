# Product

## What a person can do today (v0.30, October 2026)

| They want to | In Sage OS | Since |
|---|---|---|
| Install it like any app | One installer for Windows or a .dmg for Mac; it updates itself, signed updates only | 0.22 |
| Talk to an AI without paying | A model that runs on their own computer, chosen to fit its memory, downloaded and started from the app | 0.12, 0.23 |
| Use the AI they already pay for | ChatGPT or Gemini with a pasted key (kept in the OS keychain), Claude through Claude Code, Ollama | 0.24 |
| See what each AI costs | Tokens and spend per chat and per day, plan limits, a dated price list they can correct | 0.24 |
| Keep every chat in one place | One chat list for every AI; switch AI mid-chat and the new one carries on | 0.23 |
| Give the AI their documents | Add files or folders from the app; PDF, Word, slides, spreadsheets, text; Google Drive | 0.27 |
| Get answers from their own work | Search by meaning; each answer shows which notes and documents it read | 0.12, 0.21 |
| Turn documents into notes | The AI suggests notes (whole textbooks chapter by chapter); each waits for their OK; undo is exact | 0.13–0.20 |
| Stay in control | One Inbox for every request; trust levels per AI; a full log of what each did | 0.20 |
| Use two computers | Pair them with a code, directly, no account | 0.30 |
| Get help | Report a problem from the app, with a report they read before it's sent | 0.25 |

## Next (D46)

1. **Five minutes to value (U2):** a starter model that's ready in minutes on an 8 GB laptop; documents added on the
   first screen; a first question suggested from them.
2. **Helpers (U3):** ready-made helpers to switch on (morning brief, weekly recap, meeting prep, summarize each new
   document), each with a plain description, a schedule, results in the Inbox and a log.
3. **Clean download (U1):** signed and notarized installers, a download page, no terminal anywhere.
4. **Sync between a person's devices (P2, P3):** chats, decisions and the Bookshelf, directly between devices.
5. **Task board (A3), note-taker (M2), team bookshelves (O1).**

## Design principles that shape the product

From [MISSION.md](../MISSION.md): independent (no developer tools needed), five minutes to value, agents you can see,
local first with no outside services, the human approves what matters, plain files you can walk away with, honest
and calm screens.
