# Sage OS: company documents

The material we'd put in front of investors, kept next to the product so it stays true to what's built. Each file
answers one question a VC asks. Everything stated as fact comes from this repository (CHANGELOG, STATUS, DECISIONS,
the tests); anything not yet known is marked **TO FILL** rather than guessed.

| Read in this order | Answers |
|---|---|
| [one-pager.md](one-pager.md) | What is it, for whom, why now, where it stands, in one page |
| [narrative.md](narrative.md) | The pitch, slide by slide: the deck outline with speaker notes |
| [product.md](product.md) | What a person can do today, the five-minute demo, and what's next |
| [technology.md](technology.md) | How it works, why it's private by design, and what's hard to copy |
| [market-and-competition.md](market-and-competition.md) | Who buys, how big, and how we're different from the alternatives |
| [business-model.md](business-model.md) | How it could make money (open options, not decided) |
| [traction-and-milestones.md](traction-and-milestones.md) | Evidence so far and the milestones the next money buys |
| [risks.md](risks.md) | What could go wrong and what we do about it |
| [data-room.md](data-room.md) | Where the detailed evidence lives (decisions, tests, security, release history) |

**This repository is public.** Keep anything confidential (the raise amount, valuation, cap table, revenue
projections, named prospects, the team's personal details) out of these files: put it in the private data room and
link to it from [data-room.md](data-room.md) only by name.

**Keep it current:** when a roadmap step ships, update traction-and-milestones.md and product.md in the same release
(the release discipline already updates CHANGELOG, STATUS and ROADMAP).
